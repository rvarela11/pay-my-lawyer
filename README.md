# Pay My Lawyer

## About

Secure payment processing for law firms, and a simple way for clients to pay their attorney.

## Prerequisites

- Node.js (LTS)
- npm

## Getting Started

1. `git clone git@github.com:rvarela11/pay-my-lawyer-web.git`
2. `npm install`
3. `npm run dev` (serves at http://localhost:3000)

## Scripts

| Command           | Description                     |
| ----------------- | ------------------------------- |
| `npm run dev`     | Start the dev server            |
| `npm run build`   | Type-check and build to `dist/` |
| `npm run lint`    | Run ESLint                      |
| `npm run preview` | Preview the production build    |

## Deployment

Pushes to `main` deploy to GitHub Pages through `.github/workflows/deploy.yml`.

## Technologies

- Vite
- TypeScript
- React
- React Router
