# Pay My Lawyer

## About

An online payment and billing platform built specifically for law firms, attorneys, and legal professionals.

## Prerequisites

- Node.js (LTS)
- npm

## Getting Started

1. git clone
2. npm install
3. npm run dev

## Scripts

| Command           | Description                     |
| ----------------- | ------------------------------- |
| `npm run dev`     | Start the dev server            |
| `npm run build`   | Type-check and build to `dist/` |
| `npm run lint`    | Run ESLint                      |
| `npm run preview` | Preview the production build    |

## Technologies

- React
- TypeScript
- Vite
- ESLint

## Deployment

Deployed to GitHub Pages via GitHub Actions (.github/workflows/deploy.yml) on push to main; base path `/pay-my-lawyer/`.
